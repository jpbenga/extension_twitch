# Limites connues de la recette locale

Ces points sont à noter pendant la recette ; ils ne sont pas corrigés par une nouvelle refonte dans cette branche.

| Sujet                                         | État / conséquence                                                                                                   | Comment tester malgré cela                                                                                                 |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Pause réelle / reprise                        | **NOT_IMPLEMENTED_PENDING_PRODUCT_DECISION**                                                                         | Animer les phases ordinaires. Aucun gel local simulé.                                                                      |
| Fin anticipée d’une manche                    | **NOT_IMPLEMENTED_PENDING_PRODUCT_DECISION**                                                                         | Atteindre un résultat moteur réel ou rejouer avec confirmation.                                                            |
| Clôture volontaire / abandon                  | **NOT_IMPLEMENTED_PENDING_PRODUCT_DECISION**                                                                         | Retour à l’accueil n’arrête pas la session. Ne pas utiliser le reset comme substitut.                                      |
| Contrat des opérations absentes               | Proposition conservée, sans backend ajouté                                                                           | [Contrat proposé](ux/redesign/UNDERCOVER-LIFECYCLE-CONTRACT-PROPOSAL.md).                                                  |
| Conducteur et images locales                  | Liés à l’origine et au navigateur de préparation                                                                     | Utiliser l’adresse LAN et le même navigateur Mac ; lancer la manche suivante depuis cet appareil.                          |
| `localhost` et adresse LAN                    | Deux origines, deux bibliothèques locales                                                                            | Revenir à l’adresse utilisée initialement ; aucune purge nécessaire.                                                       |
| Images du relais après expiration/redémarrage | Médias temporaires, pas un hébergement permanent                                                                     | Repli textuel ; rouvrir la régie depuis le navigateur gardant les images pour les reconnecter.                             |
| Laboratoire rapide                            | Brouillon courant, pas une série multi-manches                                                                       | Tester le conducteur via le salon et ses invitations.                                                                      |
| Onglet joueur dupliqué                        | Le navigateur peut recopier son identité de session                                                                  | Créer un onglet neuf et y coller l’invitation, ou utiliser les liens distincts du laboratoire.                             |
| Pagination TV 6/12 joueurs                    | Groupes de trois, commande GM manuelle                                                                               | Groupe précédent / suivant ; pas d’autopagination ajoutée.                                                                 |
| Remplacement d’un état animé                  | Les états périmés sont retirés immédiatement                                                                         | Les entrées et sorties temporaires sont animées ; pas de maintien artificiel d’un ancien secret.                           |
| Vote complet                                  | Tous les votes reçus, puis dépouillement GM                                                                          | Pas de nouvelle phase serveur « vote fermé ».                                                                              |
| Miniature de préparation                      | Aperçu éditorial privé textuel, pas une distribution réelle                                                          | Tester les vraies images et associations après distribution/publication dans la session.                                   |
| Retour vers un ancien build                   | Les anciennes données sont lues par la version QA, mais les vieux schémas stricts peuvent refuser de nouveaux champs | Ne pas alterner d’anciennes branches dans le même profil de recette. Aucune donnée n’est effacée pour contourner un refus. |
| Viewer direct hors Twitch                     | Helper absent / attente d’autorisation                                                                               | Comportement attendu ; utiliser les surfaces publiques normales ou configurer Local Test dans Twitch.                      |
| Twitch authentifié / mobile Twitch            | À valider par l’utilisateur dans sa console et sur ses appareils                                                     | Tests du bundle et du Helper contrôlé séparés de cette validation.                                                         |
| Certificat mkcert Mac / iPhone                | Confiance système à effectuer sur l’appareil cible                                                                   | Ne pas désactiver TLS ; suivre le guide. Aucun certificat privé ne doit être partagé.                                      |
| OBS, iPhone, Safari réels de cette branche    | Validation humaine à faire                                                                                           | Tests Chromium et contrôles techniques LAN/HTTPS ne les remplacent pas.                                                    |
| Enchères et Qui est l’espion                  | Modules préparatoires, non jouables                                                                                  | Les cartes À venir ne sont pas des jeux terminés.                                                                          |
| Layouts et densité                            | Préférences existantes conservées, pas de refonte supplémentaire                                                     | Consigner les écarts non bloquants en UX / À REVOIR dans la checklist.                                                     |

Un premier workflow OBS réel et des explorations iPhone antérieures ont reçu des retours humains positifs ou motivé des corrections. Cette validation passée est conservée ; elle ne vaut pas validation globale de la branche QA actuelle.

Contrôle Cloud : le proxy du navigateur interdit l’adresse IP LAN privée (« Domain forbidden »). Les pages/API/SSE et images sur cette IP sont vérifiées par un client HTTP interne ; les parcours Chromium utilisent loopback. Cette restriction de l’environnement Cloud ne constitue pas un test du Wi-Fi du Mac ni une validation iPhone.
