# Captures du bundle natif — environnement automatisé

Ces PNG montrent l’implémentation réelle, alimentée par une partie Undercover serveur. Le Helper Twitch est remplacé uniquement à la frontière du test Playwright. **Ce ne sont ni des maquettes, ni des captures d’une chaîne Twitch authentifiée.** Les images des contenus sont des aplats géométriques générés pour le test.

Le fond est transparent : un visualiseur peut le représenter en noir. Le cadre correspond au viewport du test, pas aux dimensions garanties d’un Panel Twitch. La réduction 320 × 180 est un contrôle de petit Panel.
